## ✨ Fitur-Fitur Utama Website

1. **Desain Visual & Tema Bunga Daisy:**
   - Dominasi latar belakang warna **Soft Pink Pastel** (`#FFF5F8`, `#FFEBF0`, `#FFD4DF`, `#FB6F92`) yang dipadukan dengan aksen ivory, rose gold, dan tipografi berkelas (*Playfair Display* & *Plus Jakarta Sans*).
   - Unsur bunga **Daisy** yang detail dan estetis: animasi partikel kanvas kelopak bunga yang melayang lembut (*floating daisy petals*), lencana (*badges*), ilustrasi SVG presisi tinggi, dan bingkai foto dosen beraksen botanical.
   - Tombol toggle untuk mengaktifkan/menonaktifkan animasi kelopak bunga daisy sesuai preferensi pengguna.

2. **Navigasi Responsif & Pintar:**
   - Monogram AL berputar halus dengan ikon bunga daisy.

## 🚀 Panduan Menjalankan & Deployment

### Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di peramban web modern apa pun (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari), atau jalankan local server seperti Live Server di VS Code.

### Deployment ke GitHub Pages
1. Pastikan seluruh file berada di branch utama (`main` atau `master`).
2. Masuk ke pengaturan repositori di GitHub: **Settings** &rarr; **Pages**.
3. Pada opsi **Source**, pilih branch `main` dan direktori `/ (root)`.
4. Klik **Save**. Dalam 1-2 menit, website portofolio akan aktif di `https://ayu-research.github.io/`.
5. Sub-halaman proyek stasiun cuaca tetap dapat diakses di `https://ayu-research.github.io/ws/`.
