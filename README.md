## ✨ Fitur & Karakteristik Desain

1. **Estetika Soft Pink Pastel & Bunga Daisy**:
   - Palet warna harmonis blush pastel (`#FFF5F8`, `#FFEBF0`, `#FFCAD4`, `#FB6F92`) dengan kontras teks tinggi (`#261C26` dan `#3D2D3E`).
   - Sistem animasi partikel 2D kanvas kelopak bunga daisy yang melayang lembut (*floating petals*), lengkap dengan tombol toggle on/off.
   - Vektor portrait profesional akademisi **berkacamata dan berjilbab** bernuansa senada.
2. **Navigasi Bersih & Efisien**:
   - Monogram **AS** (*Ayu Sintianingrum*) berputar halus dengan ikon bunga daisy.
   - Tautan langsung ke live project *Weather Station* (`/ws/`).
   - Modal ringkasan Curriculum Vitae (CV) siap cetak/simpan ke PDF (`window.print()`).
3. **Fokus Bidang Keahlian & Riset**:
   - **Tenaga Listrik & Smart Microgrid**: Optimasi kapasitas penyimpanan baterai microgrid menggunakan Particle Swarm Optimization (PSO), manajemen aliran daya.
   - **Elektronika Daya & Sistem Tertanam**: Perancangan instrumen mikrokontroler (Arduino, ESP32), pengkondisi sinyal analog-digital, sistem otomasi pakan ikan RTC, dan pencacah ruangan otomatis.
   - **Internet of Things (IoT) & Telemetri**: Sistem pemantauan cuaca dan kelembapan media tanam real-time terdistribusi.
4. **Publikasi & Pengabdian Berdasarkan Data Nyata SINTA**:
   - Artikel ilmiah terindeks SINTA/Google Scholar dengan modal pembaca abstrak dan salin sitasi BibTeX sekali klik.
   - Pengabdian kepada Masyarakat (PKM) bidang edukasi K3 kelistrikan, etika profesi keinsinyuran di SMK vokasi, dan transfer teknologi otomasi tepat guna.

## 🚀 Deployment ke GitHub Pages

Repositori ini secara otomatis di-host menggunakan GitHub Pages:
1. Pastikan berkas berada pada branch `main`.
2. Masuk ke **Settings** > **Pages** di repositori GitHub.
3. Pada bagian **Build and deployment**, pilih **Deploy from a branch** dan tentukan root `/`.
4. Website akan langsung aktif dan dapat diakses publik pada domain `https://ayu-research.github.io`.
